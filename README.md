# Web Portfolio

Portafolio público de desarrollo web para presentar proyectos, servicios y precios iniciales a posibles clientes.

## Proyectos incluidos

- Northside Studio — barbería / servicios
- Luma Cocina — restaurante
- NOIR Supply — e-commerce / catálogo

## Incluye

- Hero comercial
- Portafolio con demos públicas
- Servicios
- Precios iniciales
- Proceso de trabajo
- Contacto
- Diseño responsive

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Antes de usar con clientes

Reemplaza el correo ficticio `contacto@ejemplo.com` por un correo de contacto real o cambia el botón por otro canal de contacto que prefieras.
